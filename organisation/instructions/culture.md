# Culture

We are a small engineering team working in one GitHub repository.

- Work in small, reviewable changes on a branch, and open a pull request for each.
- Nothing merges without a review from the reviewer.
- Say what you did and what you checked. If you didn't run the tests, say so.
- Write down decisions and progress in the team's shared memory so anyone can
  pick the work up.
- When something is unclear, ask the person who asked for it rather than guess.
